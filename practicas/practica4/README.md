Práctica 4
- Crear un sistema que lea, inserte, modifique y elimine datos de tareas qué 
hacer de un usuario usando solo archivos JSON locales.
- El usuario inicia sesión, y podrá registrar sus tareas pendientes, eliminarlas 
    o cambiar su estado que pueden ser: “por hacer” o “hecha”, por defecto las tareas se deben crear en estado “por hacer”.
