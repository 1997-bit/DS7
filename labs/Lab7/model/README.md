Laboratorio 7 
Desarrollar un servicio web SOAP en PHP que permita realizar operaciones matemáticas básicas y 
consumirlo desde un cliente PHP. 
Crear un servicio web SOAP que permita realizar las siguientes operaciones: 
- Sumar 
- Restar 
- Multiplicar 
- Dividir 
Crear un cliente PHP que: 
- Consuma el servicio SOAP 
- Envíe números al servidor 
- Muestre el resultado obtenido
