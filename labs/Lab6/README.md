Laboratorio 6 
- Crear un sistema que lea, escriba y modifique datos de productos usando 
solo archivos JSON locales. 
- Se debe crear el archivo JSON que manejará los registros del inventario de 
productos. Los productos deben contar con un id, nombre, marca, precio, 
stock, tipo de producto. 
- El sistema debe poder mostrar los productos del archivo json, y mediante 
formulario añadir o modificar productos del mismo. Todos los valores son 
modificables a excepción del id del producto.
