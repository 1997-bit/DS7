# Laboratorio 5

Una empresa ofrece los siguientes servicios, cada uno con un precio asociado:

- **Mantenimiento de computadoras** – $25
- **Instalación de software** – $15
- **Respaldo de información** – $10
- **Limpieza interna de hardware** – $20
- **Revisión de red y conexión** – $30

### Instrucciones:

- El usuario debe estar registrado en el sistema, por lo tanto se debe crear una pantalla de inicio de sesión con usuario y contraseña.
- Crear un formulario donde el cliente pueda seleccionar uno o más servicios mediante **checkbox**.
- Incluye un campo para ingresar el nombre del cliente, fecha de nacimiento, género, nacionalidad, dirección de residencia.
- **Al enviar el formulario:**
    - Se debe mostrar el nombre del cliente.
    - Se deben listar los servicios seleccionados.
    - Se debe mostrar el total a pagar.
    - Si no se selecciona ningún servicio, mostrar un mensaje de advertencia.
- Use buenas prácticas en el manejo de entradas y de las sesiones (las que considere necesarias).
